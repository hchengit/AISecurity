# Build records

One file per change, copied from `TEMPLATE.md` when PLANNING begins:

    docs/build-records/YYYY-MM-DD-<slug>.md

Boxes are checked **as the work happens, with evidence** — never afterward from
memory. The record is committed **with** the change, so the reasoning and the
receipts land in the same commit as the diff.

An unchecked box with no entry under "Skipped items" means the change is not
done. "To save time" is not a reason.

The governing document is [`../BUILD-PROCEDURE.md`](../BUILD-PROCEDURE.md).
