## 0b. Spec
- RUSTSEC-2026-0285 (rustls): TLS 1.3 handshake messages accepted across
  encryption-level boundaries. Fix: rustls >= 0.23.45.
- RUSTSEC-2026-0268 (wasmtime): guest-controlled-size host heap allocation
  through WASIp3 streams. Fix: >= 47.0.4.
- RUSTSEC-2026-0269 (wasmtime): filesystem sandbox escape via trailing
  slashes in paths/symlinks. Fix: >= 47.0.4.
- Both fixes are inside the existing `Cargo.toml` ranges (`rustls = "0.23"`,
  `wasmtime = "47"`), so only `Cargo.lock` changes. No `deny.toml` ignore is
  added (policy: prefer the fix over accepting it).
- Exposure note: wasmtime is built with `default-features = false`,
  `["cranelift","runtime","std"]`, so no WASI features, and the rule sandbox
  grants no fs/network. 0268/0269 are likely unreachable here. Updating
  anyway: that is cheaper than proving it, and the gate stays clean.
